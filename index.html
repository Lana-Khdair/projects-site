AI-Powered C++ Assignment Evaluator

Give it an assignment, a reference solution, a grading rubric and a student's C++ code. It returns a score from 1 to 5 and a written rationale.

Grading code by hand doesn't scale

Marking programming assignments takes instructors a great deal of time and effort, and it gets harder as classes grow and mistakes get more varied. Two graders can mark the same solution differently, and students often wait a long time for feedback.

How we built it

  1. Prepare the data

    513 labeled examples scored 1 to 5, audited for mislabeled entries and checked for class balance.

  2. Measure a baseline

    Score the original Mistral-7B before any training.

  3. Fine-tune with LoRA

    Train LoRA adapters on a stratified split of the data.

  4. Evaluate again

    Compare the fine-tuned model with the baseline on the same metrics.

  5. Deploy

    Publish the model on Hugging Face, serve it with FastAPI, and put a Streamlit interface on top.

What we're working on next

The scores are strong. The written rationales are the weak spot: some rationales in our training data don't match the code they describe, and the model can repeat that. Cleaning that data so the explanations are as trustworthy as the scores is our next step.
